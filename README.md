# Abhika Aura

[Visit the client website](https://abhikaaura.com/)

I started this client site in HTML, CSS and JavaScript and moved it into WordPress so the team could edit their own pages. The **Let’s Talk** form saves enquiries in WordPress so the team can review them from the dashboard.

## Manage the website

1. Activate the theme, then go to **Appearance → Abhika Aura Setup** and select **Create website pages and menus**.
2. Use **Pages** to edit content and **Appearance → Customize** to update the logo and company details.
3. Open **Enquiries** to view saved submissions.
